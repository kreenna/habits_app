# Трекер полезных привычек
Backend-сервис для управления полезными и приятными привычками с функцией напоминаний через Telegram. Позволяет пользователям создавать, редактировать и удалять привычки, подписываться на публичные привычки, а также получать уведомления о выполнении привычек.

## Описание проекта
Приложение реализует сервис полезных привычек, описывающий привычки как действия с определённым временем и местом выполнения. Поддерживаются:

- Полезные привычки (с вознаграждением или связанной приятной привычкой);
- Приятные привычки (используются в качестве награды);
- Публичные и приватные привычки;
- Периодичность выполнения с ограничениями;
- Напоминания с помощью Telegram-бота;
- Аутентификация и управление доступом.

## Ключевые особенности
Модели привычек с валидацией по правилам:

- Исключение одновременного указания вознаграждения и связанной привычки;
- Ограничение времени выполнения (макс. 120 секунд);
- Привязка связанной привычки только к приятным привычкам;
- Ограничение периодичности напоминаний (от 1 до 7 дней);
- Пагинация по 5 привычек на страницу;
- Пользователь имеет доступ только к своим привычкам (CRUD);
- Просмотр списка публичных привычек без возможности редактирования;
- Интеграция с Telegram API для рассылки отложенных уведомлений;
- Настройка CORS для фронтенд-приложения;
- Автоматическая и ручная генерация документации API.

## Технологии

- Python 3.13;
- Django + Django REST Framework;
- Celery + Redis (асинхронные задачи и планировщик);
- PostgreSQL (база данных);
- Docker (контейнеризация);
- JWT (аутентификация);
- Swagger/OpenAPI (документация);
- python-telegram-bot (интеграция с Telegram).

## Установка и запуск
Клонировать репозиторий:

```
git clone https://github.com/yourusername/habit-reminder-backend.git
cd habit-reminder-backend
```

Создать и активировать виртуальное окружение:

```
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
.venv\Scripts\activate     # Windows
```

Установить зависимости:

```
pip install -r requirements.txt
```

Настроить переменные окружения в .env:

```
DATABASE_URL=postgres://user:password@localhost:5432/habitdb
REDIS_URL=redis://localhost:6379/0
SECRET_KEY=your_secret_key
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
CORS_ALLOWED_ORIGINS=http://localhost:3000
```

Выполнить миграции:

```
python manage.py migrate
```

Запустить сервер разработки:

```
python manage.py runserver
```

Запустить Celery worker и beat для напоминаний:

```
celery -A project_name worker -l info
celery -A project_name beat -l info
```

## Интеграция с Telegram
Используется бот с python-telegram-bot.

Celery периодически вызывает задачи на отправку напоминаний по расписанию.

Пользователь получает уведомления о привычках, на которые подписан.

### Безопасность и настройки
JWT аутентификация для безопасности API.

CORS настроен для разрешения подключений с фронтенда.

Пользователи имеют доступ только к своим данным.
